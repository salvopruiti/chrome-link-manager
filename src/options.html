Link Manager

Salva un link con Shift+Click, poi aprilo dalla mini barra presente nelle pagine.

Preferiti Chrome

Seleziona una cartella esistente dalla lista, oppure lascia vuoto e usa il nome per crearne o ritrovarne una sulla barra preferiti.

Importa Da Preferiti

Importa nel database locale tutti i link della cartella selezionata, comprese le sottocartelle.

Regole URL

Una riga per dominio. Formato: dominio.tld=utm_source,utm_campaign, *.dominio.tld=ref oppure *=utm_source,fbclid per una regola globale.
